# WearAgain

Status: in development (hackathon entry).

WearAgain helps an online shopper decide what she actually needs to buy. She photographs three tops she already owns and picks three candidate outerwear items from a shop. The app renders all 9 combinations with the YouCam AI Clothes try-on API on a synthetic model, the shopper marks each one as would wear / would not wear / render error, and a deterministic solver returns the cheapest basket that satisfies her declared needs, possibly buying nothing, with a certificate showing why no cheaper basket works.

Built for the YouCam API Skin AI & eCommerce VTO Hackathon (Devpost, Perfect Corp.). No LLM calls. No real faces are used or stored by this project.
