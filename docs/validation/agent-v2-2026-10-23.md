## Manual device acceptance (not claimed as automated)

1. Android Chrome/Edge: open `/judges/`, install from the native prompt, launch from the icon, dismiss any optional UI and confirm the chosen demo and saved wardrobe persist.
2. iPhone Safari: use the app's Share → Add to Home Screen instructions, launch standalone, check keyboard/safe areas and camera/file fallback.
3. Switch offline: own clothing photos and saved examples remain; live AI/forecasts/new previews explain that a connection is required. Reconnect and verify data persists after a service-worker update.
4. Add a real garment-only photo with consent; use the synthetic avatar selected in My style. The single authorized live YouCam probe is already used, so any additional physical garment render requires a separately allocated run.

Local profiles are device storage, not authenticated cloud accounts. File transfer is explicit, not automatic synchronization. Personal-photo try-on is disabled; preview style does not prove size. Operator endpoints remain unavailable if the separate existing operator secret is absent; no secret is created or rotated by this release. Real provider verification and deployment receipts are recorded separately when executed.
